# 3D Avatar Model Directory

You can place your custom 3D developer avatar model here:
`developer-avatar.glb` (path: `/models/developer-avatar.glb`)

### Supported specifications:
- Format: `.glb` / `.gltf` (binary GLTF preferred)
- Rig: Standard humanoid armature
- Animations: Idle, Wave, Greet
- Default: If this file is absent, the portfolio automatically generates and renders the high-end procedural 3D CGI developer avatar with full kinematics, blinking, and breathing.
